# Скриншоты

Положите сюда изображения и обновите таблицу в корневом `README.md`.

Ожидаемые файлы:

| Файл | Что показать |
|---|---|
| `services.png` | окно Настройки → вкладка «Сервисы» с чекбоксами |
| `test.png` | вкладка «Тест» с примерами «до → после» |
| `history.png` | окно «История замен» с таблицей |
| `tray.png` | контекстное меню в системном трее |
| `notification.png` | тост «Ссылка исправлена» с кнопкой «Отменить» |

Требования к PNG:

- ширина ≥ 800 px;
- без личных данных (URL со статусами можно оставить — они публичные);
- тёмная тема предпочтительна (соответствует UI).
