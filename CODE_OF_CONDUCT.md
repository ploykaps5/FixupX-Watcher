# Кодекс поведения

## Наши принципы

- Уважение ко всем участникам независимо от опыта, языка, ОС и взглядов.
- Конструктивная критика кода и идей, без перехода на личности.
- Прозрачность: обсуждаем решения в issue, а не в личных сообщениях.

## Недопустимо

- Оскорбления, троллинг, дискриминация.
- Публикация личных данных других людей.
- Спам и реклама в issue / PR.

## Что делать при нарушении

Напишите мейнтейнеру через GitHub Issues с пометкой `[conduct]`
или через профиль. Все обращения конфиденциальны.

Мейнтейнеры вправе удалять комментарии и блокировать пользователей
при нарушениях.
